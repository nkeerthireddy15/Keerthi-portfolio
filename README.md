# Keerthi N — Portfolio

A clean, responsive portfolio for a full-stack MERN and React Native developer.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Main files

- `src/App.jsx` — content, projects and page structure
- `src/index.css` — complete visual system and responsive styling
- `src/assets` — project screenshots

Update the project links, email, GitHub and LinkedIn URLs directly in `src/App.jsx` when needed.
